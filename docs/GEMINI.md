# [DESIGN SYSTEM MEMORY: Halogen Kit]

Terapkan aturan UI/UX dan gaya visual berikut untuk setiap permintaan pembuatan komponen UI, halaman web, atau antarmuka aplikasi:

## 1. Palette Warna (HEX)
- **Background Utama**: `#161A21` (Dark Charcoal / Hampir Hitam)
- **Surface / Container 1**: `#1F2420` (Dark Olive Gray)
- **Surface / Container 2**: `#2A313C` (Slate Dark Gray)
- **Primary Accent**: `#ADFF2F` (High-voltage Lime Green / Neon Accent)
- **Primary Text & Light Accent**: `#F2F5F1` (Off-White / High Contrast Light)

## 2. Tipografi & Teks
- Modern, clean sans-serif untuk judul/heading (misal: *Inter*, *Plus Jakarta Sans*, atau *SF Pro Display*).
- Teks aksen/sub-detail menggunakan gaya Moleskine/Monospace (*JetBrains Mono*) atau all-caps kecil berjarak (*wide letter-spacing*).

## 3. Visual & Komponen
- **Dark theme dengan kontras tinggi**.
- Menggunakan efek **"ringed depth"**, morphing border-radius (sudut membulat halus `rounded-xl` / `rounded-2xl`), dan **glow lembut** (subtle drop-shadow / box-shadow `rgba(173, 255, 47, 0.25 - 0.4)`) pada elemen aksen neon (`#ADFF2F`).
- **Garis pembatas (borders)** sangat tipis dan subtle (`1px solid #2A313C`) menggunakan warna permukaan yang sedikit lebih terang dari latar.
